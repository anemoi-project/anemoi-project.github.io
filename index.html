03 / How it works

Think in 2D.
Compute only what matters.

Visual tokens carry spatial structure. EVG keeps it intact long enough to route attention by region, then assigns precision to the retained work.

01

Draft Attention

Build a lightweight 2D importance map before committing to full attention.

Read the paper ↗
02

Ragged 2D execution

Pack connected visual regions into exact-cover blocks and execute only retained pairs.

Explore the design ↗
03

Mixed precision

Protect critical structure in FP16 while routing suitable retained work to lower precision.

05 / Quick start

From clone
to first frame.

One setup script prepares the pinned runtime. The launcher downloads the required MiniMax-H3 components, builds native extensions, and selects a valid GPU count.

  • Linux
  • SM89 GPU · RTX 4090
  • CUDA + nvcc
  • Conda
  • First-run network
Reproduction guide

evg / quick-start

# Clone and enter EVG
$ git clone https://github.com/evg-project/evg.git
$ cd evg

# Prepare the runtime
$ scripts/setup_conda_env.sh
$ conda activate evg

# Generate the demo video
$ scripts/run_minimax_h3.sh
✓ Output → outputs/minimax-h3/mpa-ragged2d-mixed/out.mp4
